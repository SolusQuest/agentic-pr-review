# S5 native R3 production branch retirement

Status: historical implementation-step record. Its counts and source coordinates describe that intermediate revision. The final source closure and current generic owners are now verified together by [`assertion-dispositions.mjs`](../../runtime/tests/SolusEvaluationFixture/assertion-dispositions.mjs) and its existing successor/migration ledgers. Original assertion and disposition JSON records remain immutable; intermediate source-checker functions have been consolidated. Source identity never qualifies installed SDK execution.

The direct command now has one execution composition: current Solus when the
managed package is present, and the existing explicit composition-required
failure otherwise. Its authorization, snapshot admission, independent lineage,
invocation identity and result publication checks remain. The old historical
activation arm and its private deterministic transport no longer execute.

The retired production family comprises the native R3 application, request and
candidate; its restorer, dependencies and unavailable factory; the historical
command entry and activation profiles; and the old native `CommitAsync`,
SESSION-specific preflight and candidate-only helper closure. The historical
negative producer still uses its pinned original source. No current reader,
serializer or compatibility converter replaces that producer.

Current Solus retains `CommitPreparedAsync`, the real transaction factory and
prepare/reconcile/accept engine, time and receipt checks, lineage publication,
claim behavior and owned-buffer cleanup. Thirty-one retained durable method
declarations are byte-identical to the retirement input. The sole shared method change
is `Service`: it receives the same constructor-selected admission without a
native default. Factory and transaction construction reject a missing admission
before a store factory, store operation or key operation can run. This cannot
select fresh execution or manufacture authority.

Current environment credential capture, key resolution, manifest file access,
result and diagnostic types, `ILiveAgentFreshProcessProof` and the actual HTTP
transport proof remain. The typed historical verifier keeps its chat factory and
strict component contract; deleting a native runtime factory does not retire that
reader or change historical receipt counts.

The [closed source record](../../runtime/tests/SolusProductionCutoverFixture/s5-r3-production-retirement.json)
and [verifier](../../runtime/tests/SolusEvaluationFixture/assertion-dispositions.mjs)
bind the retained durable bodies, ten precisely affected architecture methods,
twenty-seven unchanged architecture methods, all existing prepared-engine
assertions and the constructor refusal controls. Two original typed replay tests
retain their thirteen cases and assertions through a fixed seven-message
readonly fixture predicate. Its five methods and two constants move verbatim,
except for an alias to the existing identical framing constant. Those authored
messages do not establish actual restore or SDK context import.

The real managed fault proof additionally checks APR admission reference identity
under its existing current authority, direct composer and typed transaction
seed. It inspects APR objects only, uses no SDK private fields or synthetic SDK
execution counters, and does not turn the intentionally invalid opaque seed into
an SDK import proof. This added observation requires execution with the affected
installed package; native compilation and a source digest cannot qualify it.

Original V1 identities and its 152-row mapping remain unchanged. Earlier
retirement reasons, methods and counts remain their original evidence; current
owner source coordinates are refreshed only over unchanged named bodies, apart
from the explicitly removed prepared-constructor dependency. Other SESSION,
Replay, Growth, Economics and supporting AOT consumers still require their own
closed dispositions. This branch retirement does not complete S5 by itself.

The sole residual-reference rule for the removed deterministic transport is
retired with that source. Its input declaration and exact removal are recorded;
reference discovery and all other residual rules remain unchanged.
