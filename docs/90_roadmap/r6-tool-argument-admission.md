# R6 tool argument admission investigation (#291)

The September 23 [bounded live observation](r6-live-observation.md) restored an accepted session and received a successful provider response, then stopped at `agent_tool_arguments_invalid` before executing a tool. Its safe report does not retain the rejected tool name or argument shape. The exact historical response cannot be reconstructed, and this investigation does not attribute that failure to a particular field or model behavior.

Offline tests reproduced a separate concrete mismatch in the request path. `AgentToolArguments.Try*Provider` correctly accepts omitted optional fields and writes canonical SESSION arguments with explicit nulls: `list_files` stores `prefix` and `after`, `list_changed_files` stores `after`, and `search_text` stores `path`. `AgentLoop` uses those canonical bytes in history; restore preserves them. The DeepSeek request writer previously copied that history into `tool_calls[].function.arguments` unchanged. The advertised schemas permit strings for these optional fields, so the next provider request contained explicit nulls outside their schema. The [SESSION contract](../20_architecture/agent-session-format.md) requires absent `search_text.path` to be omitted on the provider-facing side.

The correction projects only those three validated canonical historical calls back to their provider-facing omitted-field spellings when writing a DeepSeek request. Durable SESSION bytes, hashes, restore validation, tool schemas, current response admission, and the adapter descriptor remain unchanged. Build identity and the exact request bytes distinguish the corrected execution. Explicit null in a _current_ provider response still fails before preflight or dispatch, including when a valid tool call precedes it in the same response.

Synthetic tests show the pre-fix request mismatch, the corrected fresh and restored wire requests, and rejection of current explicit-null arguments in fresh and restricted-state replay paths. The restored rejection leaves its accepted predecessor readable and produces no accepted successor or tool execution. These tests are mechanism evidence, not a replay of the unavailable live response. They did not authorize another live campaign, automatic retry, parser relaxation, economics result, or model-quality conclusion.
