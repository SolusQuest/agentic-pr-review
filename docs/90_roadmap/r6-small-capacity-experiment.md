# Isolated reduced-capacity experiment

This branch is an experimental derivative of `bf9bb8f8f226f9742c55d3b1788819326716ebed` for issue #296. **Do not merge or distribute its runtime.** Its sole runtime alteration is `AgentLimits.Messages = 32` instead of the production value 64. Canonical limit identities consequently change. All continuation, state, token, tool and other resource limits retain their original values. Results cannot establish the adequacy of the production capacity or complete the historical C/D populations.

The test executable's `small-capacity` command admits exactly two replay stages, up to twelve tools-growth stages and two post-reset stages, with the explicitly identified `small_capacity_event_v1` stop rule. It reserves all sixteen possible child allocations before credential access. Each child uses the existing clean-source/build admission, private IPC, bounded real Agent/provider path, receipt checks and restricted-state service.

Successful growth stages are accepted and independently read back. After at least two accepted growth stages, an observed capacity rejection must leave the selected predecessor readable. Only then are the remaining growth slots recorded as unattempted/not-needed and the preauthorized local state reset executed. Reset must verify absence before a new session accepts generation zero and another fresh process restores it. Exhaustion without capacity is insufficient. Other failures stop the experiment; no retry, summarization, fabricated history or capacity relocation occurs.

The report format is `apr.r6.small-capacity-experiment.v1`, with all sixteen slots, attempted evaluation outcomes, per-call usage and failure observations retained. It deliberately has no native C1 journal/pricing export and does not pass the ordinary economics report reader. Reference usage pricing is independently derived with the frozen tariff; unknown usage stays unknown. This is real-provider integration with local synthetic repository/state storage, not production GitHub Host publication or production-default capacity evidence.

Tests named `SmallCapacity...` verify successful measured rejection/reset/continuation, preservation and attribution of skipped slots, unrelated failure stops, and selection rejection before secret access. The ordinary production baseline and its prior CI evidence remain separate from this deliberately altered experimental build.
