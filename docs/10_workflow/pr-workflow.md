# PR Workflow

Use the shared [PR workflow](../shared/standards/pr-workflow.md) and [PR publishing skill](../shared/skills/pr-publishing/SKILL.md), with the APR additions below. The shared draft-publication default and bounded no-issue path apply when the current task leaves those choices open.

## APR Requirements

Use the repository's [PR template](../../.github/PULL_REQUEST_TEMPLATE.md), including its summary, changes, validation, tracking, agent checklist, and applicable breaking-change sections.

Follow [APR repository policy](repository-policy.md) for local operation restrictions and [release policy](release-policy.md) for release and closeout requirements.

Use [APR validation](validation.md) for commands and affected runtime proofs.
