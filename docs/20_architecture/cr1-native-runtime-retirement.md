# CR1 native execution retirement

CR1-R7 [#403](https://github.com/SolusQuest/agentic-pr-review/issues/403) removes APR's generic AgentLoop, MinimalChatClient, native retry/budget/deadline machinery and historical Host runner. The selected managed production compositions use Solus execution. APR retains trusted request materialization, readonly logical values and serialization, canonical identities, domain tools, correction feedback, grounded terminal validation, accounting, Host authorization, encrypted state and publication authority.

## Current and historical consumers

Fixed Host and evaluation workloads execute fixture-owned tool plans through the actual APR preflight, snapshot tool, result-admission and terminal validators. Tools are chosen before work starts. An observed response cannot select more work or authorize a retry. Authored failure outcomes exercise actual Host failure, accounting and nonmutation boundaries; they do not demonstrate an engine limit trigger.

The existing shared evidence-contracts assembly owns the internal IAuthoredResponseSource; the historical factory remains in LiveAgentVerifierFixture. The proof payload does not reference an executable synthetic fixture. These test contracts are absent from the production assembly. Readonly prefix, replay, quality, report and economics consumers retain their domain distinctions. Authored logical values and synthetic accounting facts are not provider sends, SDK context import or installed-runtime qualification.

The supporting AgentLoopAotFixture project now proves actual APR snapshot operations and grounded terminal admission in a closed environment. Its execute route reports APR_AGENT_DOMAIN_EXECUTION_OK. The old negative and r7-retry routes return exit 2 with APR_NATIVE_GENERIC_EXECUTION_RETIRED, without writing results or state. Refusal is not successful execution of an old scenario. The original negative-case manifest, limit table and goldens remain historical records. Framework/AOT supporting gates and the mandatory managed archive routes remain separate.

Current capacity Host receipts use apr-r7-authored-capacity-host-v1, zero provider-call/send counters and explicitly named actual tool/input observations. Their failure outcomes are authored Host boundary inputs. The original historical capacity and S5 Host receipt domains remain readable with their original meanings.

## Assertion ownership

The existing [assertion-dispositions primary verifier](../../runtime/tests/SolusEvaluationFixture/assertion-dispositions.mjs) owns the [R7 successor](../../runtime/tests/SolusEvaluationFixture/r7-assertion-successor.json). It preserves the original 152-row mapping, five format retirements, S5 dispositions and historical file identities. Each R7 override identifies the exact original body, attributes and assertion expressions and a current body or explicit retirement. A retained body in a changed file still requires its original body hash and its actual new byte range. Retired files must remain absent.

The seven S5 census files currently contain 116 real attributed methods, including the renamed readonly failure-envelope owner. That census does not establish equivalent coverage. Protected path, policy-prefix and invalid trusted-budget predicates have explicit current APR owners; native 64-call/512-tool boundaries and Minimal carrier normalization are retired contracts. Actual selected-runtime budget, retry, cancellation, correction and bridge-boundary qualification belongs to the installed Solus fixtures. Source identities do not prove that those fixtures ran.

The [original loop contract](agent-loop-contract.md), [R2 abstraction decision](ai-abstraction-decision.md) and native count table retain historical interpretation. No current engine reconstructs the old protocol for compatibility. Genuine legacy-state qualification retains its separately pinned historical producer.

## Qualification

A production assembly change requires a newly built managed archive and final-head Ubuntu 24.04 x64 qualification under [APR validation](../10_workflow/validation.md). Local domain tests, source ownership, compiled-IL guards, old archives and historical AOT results cannot substitute for that execution. The selected package/profile, provider credentials, context authority and state/publication requirements are unchanged by retirement.
