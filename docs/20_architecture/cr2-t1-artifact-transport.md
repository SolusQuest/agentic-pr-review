# CR2 T1 artifact transport

[T1 #449](https://github.com/SolusQuest/agentic-pr-review/issues/449) implements the runnable hybrid in the frozen [CR2 contract](./cr2-cli-action-contract.md). The live `AcceptedStateProductionDependencies.CreateArtifactStore` creates `GitHubArtifactRestrictedStateStore` with C# REST. Node executes the official SDK upload and returns provisional SDK facts; C# independently verifies the artifact before reporting a committed store result. This does not qualify the later final composite or hosted interoperability.

## Production ownership

`GitHubArtifactRestClient` owns fixed GitHub API routes, credentials, bounded responses and anonymous signed archive downloads. `ArtifactTransportFormat` reads the unchanged S2 ZIP/envelope, checks the physical family name, encrypted digest/size and producing run/attempt. Metadata and verified-record reuse share a bounded, wiping cache. Expiry is checked against current UTC even after a conditional 304.

`ArtifactRestBudget` owns authenticated attempts, primary observations, sticky rate-limit refusal, pacing and mandatory upload/delete observation reservations. Ordinary invocations retain their existing uncapped profile; protected proof retains its measurement/final caps. `ActionHostComposition` owns one lazy artifact store for the invocation, so repeated restore composition shares the ledger and cache. A subsequent invocation gets a fresh owner. The protected private artifact budget receipt comes from this C# ledger; Node validates its framing, profile and launch identity and forwards it after SDK quiescence.

The transitional `upload_immutable` request still carries the logical name, confined raw encrypted source, digest and minimum expiry. Its reply contains only operation/correlation, dispatch, failure and nullable artifact ID/archive hash/archive size receipt. C# rejects the historical committed-metadata reply. Failed or lost post-dispatch observation remains ambiguous and does not cause an upload replay. Exact deletion verifies the expected object, dispatches once, invalidates observations and requires fresh absence after acknowledged deletion; a lost acknowledgement remains unknown. Journal-authorized acceptance writes retain their independent reconciliation token after business cancellation.

T2 owns moving carrier encoding, physical naming and retention-day arithmetic into C#, narrowing the request, and removing the broad request types. C2 owns the ordinary CLI/input cutover; this change does not replace that entry contract.

The historical Node REST/cache/budget/operations/server modules are explicitly named `historical-*.fixture.ts`. Their old six-operation tests, synthetic fixture server, capacity fixture and managed archive supporting bridge select them explicitly. `HistoricalFixtureArtifactBridgeStore` is linked only into named test/verifier projects. The framework verifier uses its own historical namespace; the production factory never selects it. Original pinned protected/AOT evidence remains at its original inputs. These fixtures preserve comparison evidence and are not production fallbacks or proof of the new transport.

The ordinary generated Action excludes those historical REST modules. Current production upload tests and C# tests supply replacement evidence; keeping historical negatives does not transfer their assertions to unexecuted new code. Package-independent synthetic Linux Host execution does not establish either gate or a live provider result.
