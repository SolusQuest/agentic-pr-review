# Code Conventions

Use the shared [content conventions](../shared/standards/conventions.md) for repository prose and information handling. The following toolchain choices remain APR-owned.

- TypeScript with strict mode.
- ES modules (`"type": "module"` in `package.json`).
- Use `vitest` for tests.
- Use `prettier` for formatting.

Do not wrap commit messages, PR bodies, issue bodies, or comments in decorative marker strings.
