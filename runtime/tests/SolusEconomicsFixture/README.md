# Solus economics evidence fixture

This managed-only V2 fixture executes the selected installed packages through the actual fresh state-commit and restored Host compositions. It links only existing synthetic Host ports; its controlled provider, observer, strict report reader, reference-price projection and independent Node oracle are owned here. It changes no production selection, provider adapter, retry policy or state authority.

The trusted package-proof workflow invokes `bash runtime/scripts/verify-r6-economics.sh managed`. It supplies the previously verified package cache without a restore token. The verifier restores with no feeds, compares loaded DLLs to original package archives, runs seven named self-test suites and fourteen bridge scenarios, and requires thirty review/recovery children, eighteen authenticated readbacks, ninety-two Host HTTP-handler entries and thirty hostile probes. These are required authored populations, not a completed qualification receipt. HTTP-handler entries include unknown dispatch and establish no remote delivery or billing.

`Program.cs` produces bounded ephemeral JSON. `Contracts.cs` strictly reads it, validates typed Solus associations/coverage and rejects unknown/duplicate members. `oracle.mjs` independently checks source/build/corpus, fixed controlled measurements, full historical/current identity separation and per-call wire populations. A coherent rebound measurement substitution that preserves totals and prices still fails that outside oracle; structural admission and hashes do not authenticate a producer.

Actual provider wire message tokens and ordered settings are hashed without reserialization or scrubbing. The complete seed prefix and separately normalized final assistant are checked against the restored wire. The current Caller inspection and terminal answer use the genuine historical Lookup tool fact without reacquiring it. The supported same-head snapshot is unchanged; no deleted-file or live-model-recall claim is made. Prefix stability, nullable measurements, synthetic reference amounts, product acceptance and durable acceptance remain independent.

`self-test` runs portable contract/normalization/price/comparison/wire/freeze/supplemental-retry checks. A local source-only build is useful supporting evidence, never installed-package qualification. Two explicitly correlated exchanges test retry representation without enabling retries in the production profile. There is no live provider campaign, current tariff, invoice, cache-control intervention, quality upgrade or public compatibility promise.

The outer Python supervisor owns deadlines, bounded captures and process groups. The Node verifier audits actual runtime/reader children with strace, including a mandatory network-detection control. All ordinary calls use in-memory HTTP and the real local AF_UNIX artifact bridge. Child/helper environments are allowlists. Successful proof deletes owned private state; failures retain private evidence without uploading raw reports, package bytes or diagnostics. Only fixed failure codes and public source locations can be printed.

The explicit `all`, `framework` and `aot` modes continue the historical R6 evaluator regression. They do not execute this fixture. Both retained regression and actual exact-head managed qualification are required; see [validation](../../../docs/10_workflow/r6-economics-validation.md).
